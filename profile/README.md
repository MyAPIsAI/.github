# MyAPIsAI

**One API. A World of AI Models.**

Connect once. Build with the AI models you choose.

MyAPIsAI develops infrastructure for integrating, routing, and managing AI model APIs. Our goal is to make multi-provider AI integrations easier to build, deploy, and operate.

## Featured Project: StarHub

**[StarHub](https://github.com/MyAPIsAI/starhub)** is a self-hosted AI API gateway built with Go. It unifies different upstream AI providers behind developer-friendly APIs and provides tools to manage channels, users, tokens, quotas, and usage.

### Highlights

- **Unified API access:** OpenAI-compatible and Claude-compatible request interfaces.
- **Multi-provider connectivity:** Integrations for OpenAI-compatible services, Anthropic Claude, Google Gemini, and AWS Bedrock.
- **Flexible routing:** Multi-channel routing with failover support.
- **Quota and billing controls:** Pre-charge, usage-based settlement, and refund handling.
- **Built-in administration:** Web console for managing channels, models, users, and usage.
- **Self-hosted deployment:** A Go-based server with an embedded web console and SQLite storage.
- **Beyond text:** Documented endpoints for embeddings, reranking, audio, images, video tasks, and realtime sessions.

4. Connect your application through the supported API endpoints.
